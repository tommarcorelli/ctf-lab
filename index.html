🛠️ Créer une machine

        
      

      

        Décris une machine en JSON (même schéma que machines.js, regex d'exploit en
        chaînes). « Valider & charger » la teste dans le vrai moteur et l'ajoute à la liste
        (bac à sable, non sauvegardée). « Télécharger .json » l'exporte pour l'intégrer à
        machines.js.
      

      
      

      

        
        
        
        
        
      

    

  


  

    

      

        
▶️ Replay de session

        
      

      

        Rejoue tes commandes et leurs sorties façon asciinema — sans les ré-exécuter,
        donc ta progression n'est pas touchée. Exporte le replay en .json pour le rejouer
        plus tard ou le partager.
      

      

      

        
        
        
        
        
      

    

  


  

    

      

        
🧪 Bac à sable libre

        
      

      

        Monte un système de fichiers à toi pour t'entraîner aux commandes (ls,
        cat, find, grep, vim, pipes…),
        sans flag ni score. Format : un objet { "chemin": "contenu" }
        (une chaîne = fichier, {} ou un / final = dossier ; chemins relatifs
        à ~ sauf s'ils commencent par /).

🧠 Buffer overflow (pédagogique)

        
      

      

        Une fonction lit une entrée dans char buf[16] sans vérifier la taille. La pile
        contient ensuite le RBP sauvé (8 o) puis l'adresse de retour
        (8 o, offset 24). Fais déborder le buffer pour écraser l'adresse de retour avec l'adresse de
        win() = 0x401156. Aucun code n'est réellement exécuté —
        c'est un schéma pédagogique.
